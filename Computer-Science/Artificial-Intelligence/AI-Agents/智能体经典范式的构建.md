# 智能体经典范式构建

## ReAct
- 定义：思考与行动是相辅相成的，他通过一种特殊的提示词工程来引导模型，使其每一步的输出都遵循一个固定的轨迹
- 特点：
1.Thought:智能体内心独白，他会分析当前情况，分解任务，制定下一步计划，或者反思上一步的结果<br>
2.Action:调用一个外部工具来采取行动<br>
3.Observation：执行action后从外部工具返回的结果<br>

## Plan-and-Solve
- 阶段:
1.规划阶段：首先智能体会接受用户完整问题，他的第一个任务不是直接去解决问题或调用工具，而是将问题拆解并制定出一个清晰，分步骤的行动计划<br>
2.执行阶段：在获得完整的计划后,智能体进入执行阶段。它会严格按照计划中的步骤,逐一执行。每一步的执行都可能是一次独立的 LLM 调用,或者是对上一步结果的加工处理,直到计划中的所有步骤都完成,最终得出答案<br>

## Reflecion
- 三步循环：
1.执行：首先,智能体使用我们熟悉的方法(如 ReAct 或 Plan-and-Solve)尝试完成任务,生成一个初步的解决方案或行动轨迹。这可以看作是“初稿“<br>
2.反思：接着,智能体进入反思阶段。它会调用一个独立的、或者带有特殊提示词的大语言模型实例,来扮演一个“评审员”的角色.这个“评审员”会审视第一步生成的“初稿”,并从多个维度进行评估,例如:<br>
    1.事实性错误:是否存在与常识或已知事实相悖的内容?<br>
    2.逻辑漏洞:推理过程是否存在不连贯或矛盾之处?<br>
    3.效率问题:是否有更直接、更简洁的路径来完成任务?<br>
    4.遗漏信息:是否忽略了问题的某些关键约束或方面? 根据评估,它会生成一段结构化的反馈(Feedback),指出具体的问所在和改进建议<br>
3.优化 (Refinement):最后,智能体将“初稿”和“反馈”作为新的上下文,再次调用大语言模型,要求它根据反馈内容对初稿进行修正,生成一个更完善的“修订稿”。<br>
